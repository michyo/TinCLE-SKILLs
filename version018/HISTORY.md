## Version 0.18 - 2026/11/09 [ Jules ]

* **Automated Exact-Literal Text Substitution Utility (`oxtailst` / `SKILL_ADD2.md`)**: Introduced "oxtailst" (Oxtail stew: Overwriter and eXchanger for Textfile's Assigned Inline Letters Substitution Tool) to the extended foreign toolchain. Designed to safely automate pinpoint string replacements across source files, batch scripts, and documentation, this pure C99 command-line utility strictly utilizes exact-literal matching to completely eliminate the catastrophic cascading risks of traditional regular expression engines. By automatically generating `.bak` backups and executing in-place modifications, `oxtailst` empowers autonomous AI agents to perform structural parameter swaps and version bumps with absolute economy—permanently eliminating the need to burn precious API tokens or risk hallucinations by regenerating massive, multi-thousand-line source files.
* **Standalone JavaScript Minification & Obfuscation Utility (`jalma` / `SKILL_HL.md`)**: Introduced "jalma" (JAvascript Local Minifier & Alterer) to the TinCLE JS toolchain. Forged as a highly compact, Pure C99 command-line executable powered by an embedded QuickJS runtime, `jalma` completely eliminates the need for the heavy, bloated Node.js ecosystem. It meticulously strips whitespace, removes dead code, and mangles top-level variable names to drastically shrink JavaScript payloads—often halving the size of pure Canvas logic. This extreme payload reduction unlocks advanced, highly constrained deployment strategies like URL-embedded base64 distribution, while simultaneously providing robust logic concealment to protect the creator's procedural algorithms as a secure black box prior to Web or NW.js desktop compilation.
* **MML to Standard MIDI File Converter (`arancini` / `SKILL_MID.md`)**: Introduced "arancini" (Ai Rhythmic Array Notation Converter to Instrument-Neutral Interface) to the extended foreign toolchain. Engineered as a pure C99 command-line utility, it parses raw MML compositions originally intended for the `pisstrak` synthesizer and precisely encodes them into universal Standard MIDI File (SMF Format 1) `.mid` files. By perfectly encapsulating the AI's rhythmic notation into an instrument-neutral interface, `arancini` liberates complex musical arrays from proprietary raw audio waveforms, empowering creators and AI agents to export their exact rhythmic logic directly to any modern DAW or standard MIDI sequencer worldwide.
* **Retro Audio Chiptune Renderer (`tiramisu` / `SKILL_MID.md`)**: Introduced "tiramisu" (TIngling Retro Audio MIdi SUperfuser) to the peripheral sweets toolchain. Engineered as an independent C/C++ standalone command-line executable, it completely sheds heavy GUI dependencies like Qt. Leveraging the ChiptuneMIDI engine alongside libogg and libvorbis, it directly ingests external Standard MIDI (`.mid`) files and renders them into rich, ready-to-play 8-bit retro WAV or OGG audio. Acting as the ultimate integration bridge, `tiramisu` empowers AI agents and creators to seamlessly merge pre-existing musical assets into the standard TinCLE build flow, guaranteeing a perfectly fused, retro-tingling sonic aesthetic without ever relying on the end-user's local OS soundfonts.
* **Standalone High-Fidelity Image Normalization Utility (`ebisen` / `SKILL_ADD2.md`)**: Introduced "ebisen" (Easy Best-fit Image Size Equalizing Normalizer) to the peripheral sweets toolchain. Engineered as a blazing-fast, pure C99 command-line executable, it eliminates the need for heavy external GUI graphics editors. Utilizing high-quality Mitchell/Lanczos resampling via the `stb_image` library, it empowers AI agents and creators to instantly normalize scattered, raw visual assets into strictly unified dimensions across four deterministic modes (Fit, Crop, Pad, and Stretch). Featuring in-place output optimization, `ebisen` allows autonomous agents to flawlessly align and overwrite massive asset directories directly from the command line, drastically reducing file-renaming friction and strictly conserving precious API tokens.
* **Native OGG Format Support for Procedural Audio (`fartbox` / `SKILL_FB.md`)**: Upgraded the "fartbox" (Frequency Audio Rendering & Tuning BOX) 1-shot sound effect synthesizer to natively encode and output high-fidelity OGG audio files alongside traditional WAVs. By directly embedding the libogg and libvorbis encoding pipelines into the core C99 renderer, this critical enhancement empowers AI agents to instantly generate, mutate, and export highly compressed procedural sound effects. This drastically reduces final binary payloads and runtime memory footprints—especially crucial for WebAssembly deployments—completely eliminating the need for heavy external audio compression middleware.
* **Standalone Audio LUFS Normalizer & Trimmer (`jalebi` / `SKILL_ADD2.md`)**: Introduced "jalebi" (Jules Audio Lufs Equalizing & Balancing Improver) to the peripheral sweets toolchain. Engineered autonomously by our core AI developer Jules, this pure C99 command-line utility natively embeds the `libebur128` logic and `libvorbis` processing to automatically equalize the overall loudness of disparate audio assets to a comfortable -15 LUFS. Furthermore, it intelligently detects and trims absolute or near-silence from the start and end of raw audio tracks, ensuring seamless BGM loops and immediate sound effect playback. By standardizing chaotic audio levels generated by various procedural engines or AI models without relying on heavy external DAWs, `jalebi` guarantees that every auditory impact in the TinCLE ecosystem hits with perfect balance and zero latency.
* **Standalone AI-First Map Editor (`bandpisa` / `SKILL_BA.md`)**: Introduced "bandpisa" (Bandeja paisa: Blueprint Arranger & Network Delineator for Plating Imagined Spaces to Ai) to the human utilities toolchain. Engineered as a highly responsive, standalone Windows executable powered by Dear ImGui, this visual map editor is purpose-built to bridge human imagination and autonomous AI game development. It empowers creators to seamlessly paint multi-layer tilemaps and intuitively delineate complex spatial semantic areas (e.g., "Castle", "Boss Arena", "Treasure") via overlapping annotations. By exporting strictly structured, zero-ambiguity JSON map descriptors, `bandpisa` completely eliminates the need for error-prone AI vision models, allowing AI agents to instantly digest exact level topologies and gameplay semantics for rapid, flawless game code generation.
* **Event Callback Multicasting (`tincle_set_event_callback` / `SKILL.md`)**: Re-engineered the core SDL event interceptor system to fully support multi-cast callback registration (up to 16 concurrent listeners). Previously restricted to a single overwriteable function pointer, the new implementation empowers autonomous AI agents and developers to safely inject and stack multiple independent UI extensions (like `gatochoc` or `cococake`) without collision. Featuring strict duplication guards, a new `tincle_remove_event_callback` API for dynamic lifecycle management, and guaranteed event consumption routing (preventing "punch-through" bugs by aborting standard game logic immediately when an addon returns `true`), this core upgrade permanently resolves extension conflicts and unlocks true modular UI stacking for the TinCLE ecosystem.
* **Absolute Runtime Decoupling for Core Graphics (`SDL2_gfx.dll` / `SKILL.md`)**: Upgraded the core 2D graphics extension library by transitioning to a fully bespoke, statically linked C99 build pipeline. Previously, standard upstream distribution binaries implicitly relied on the heavy Visual C++ Redistributable (`VCRUNTIME140.dll`), introducing a hidden environmental vulnerability. By surgically compiling and statically embedding all required system APIs natively, the updated `SDL2_gfx.dll` severs all ties to the MSVC ecosystem, achieving 100% true standalone execution. This architectural purification guarantees that TinCLE games will launch flawlessly even on completely clean, factory-state Windows installations, fiercely cementing the engine's absolute commitment to zero-dependency, ultra-lightweight deployment.
